KingdomOS v8
- Drag dashboard widgets to rearrange. Layout saves automatically.
- Calendar marks busy/protected time and free time.
- Work hours are protected by default and the fit finder avoids them.
- Add busy blocks for anything unavailable.
- Use Calendar > Find Time to place studies, Uber, family, hobbies, reading, or home tasks.
- Settings control sleep/day guardrails.
Upload this folder to Netlify, then install from Chrome using Add to Home Screen.
